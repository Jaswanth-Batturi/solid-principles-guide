# SOLID Principles Guide

Interactive learning site for the five SOLID principles — same flow as [design-patterns-guide](https://github.com/Jaswanth-Batturi/design-patterns-guide):

**Analogy → Problem → Code → Compare → Run it → When to use → Quiz**

Each principle uses one consistent real-life example with complete, runnable Java (problem vs fixed).

## Principles

| Letter | Principle | Example thread |
|--------|-----------|----------------|
| **S** | Single Responsibility | Restaurant — waiter, chef, cashier |
| **O** | Open/Closed | Shipping promos — plug-in rules |
| **L** | Liskov Substitution | Car rental — any car drives |
| **I** | Interface Segregation | Phone vs office copier |
| **D** | Dependency Inversion | Light switch + injectable bulbs |
